# 🚀 Personal Portfolio

Welcome to the repository for my personal portfolio website! This project is a custom-built space designed to showcase my journey, technical skills, and creative work.

### 🌐 [Live Demo](https://LahiruDevinda.github.io/portfolio/)

---

## 🛠️ Built With

This project focuses on clean, efficient code using core web technologies without the need for heavy frameworks.

* **HTML5:** Semantic structure for better SEO and accessibility.
* **CSS3:** Modern styling using Flexbox, CSS Grid, and Custom Variables for a responsive design.
* **Vanilla JavaScript:** Custom logic for UI interactivity, navigation, and smooth animations.

## ✨ Key Features

* **Fully Responsive:** Seamless experience across mobile, tablet, and desktop devices.
* **Performance First:** Fast loading speeds with zero external dependencies.
* **Project Gallery:** A curated display of my latest development and design work.
* **Contact Section:** A streamlined way for visitors and recruiters to reach out.

## 🚀 Getting Started

To run this project locally:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/your-repo-name.git](https://github.com/LahiruDevinda/portfolio.git)
    ```
2.  **Open the project:**
    Simply open the `index.html` file in your preferred web browser.
